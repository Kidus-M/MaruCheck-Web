# Next.js: read version-matched documentation before coding

Before changing Next.js behavior, read the relevant documentation in `node_modules/next/dist/docs/`. The installed docs match this repository's exact framework version and take precedence over remembered APIs.

Use the App Router and Server Components by default. Add Client Components only when browser state, effects, or event handlers require them.
